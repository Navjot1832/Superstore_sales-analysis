# Superstore Sales Analysis

## Project Overview
Sales performance analysis of a US retail company using SQL, Excel and Power BI.

## Tools Used
- MySQL — data analysis queries
- Excel — data cleaning
- Power BI — interactive dashboard

## Key Insights
- West region generates highest sales ($713K) and profit ($106K)
- Tables sub-category losing $17,725 despite strong sales
- High discount orders generate negative profit (-$111 avg)
- Technology category most profitable at $145K profit
- Texas generates $169K sales but loses $25K in profit

## Files
- superstore_analysis.sql — all 8 analysis queries
- Superstore_Clean.csv — cleaned dataset
- Superstore_Sales_Analysis.pbix — Power BI dashboard
